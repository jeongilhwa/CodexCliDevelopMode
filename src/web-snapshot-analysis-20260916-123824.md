## 결론

이 스냅샷은 **옥션 판매진행내역**으로 진입한 ESM Plus 공통 셸이다. 실제 판매/정산 데이터 화면은 `iframe#innerIFrame`으로 분리되어 있으며, 그 문서는 캡처 폴더에 포함되지 않았다. 따라서 판매 내역의 표, 날짜·상태 필터, 행 단위 동작, 내부 API 호출은 이 자료만으로 검증할 수 없다.

## 화면 구조와 주요 DOM

1. 최상위 앱: `#app > .homemain`
2. 공통 헤더: `header.header`
   - ESM PLUS 로고, 판매자 가이드·파트너센터·스타배송·광고센터
   - 로그인 판매자 표시, 로그아웃, 동시접속 현황, 도움말, 채팅상담, 알림 버튼
3. 좌측 내비게이션: `.box__navigation`
   - 전역 검색: `.box__nav-search`
   - 대분류/하위 메뉴: `.box__nav-menu`
   - 현재 선택: `정산 관리 > 옥션 판매진행내역`
4. 콘텐츠 영역: `.box__container`
   - 이미지 상세용 레이어: `#layer-image` (캡처 시 표시 상태로 보이나 이미지 URL은 비어 있음)
   - 실제 업무 화면: `iframe#innerIFrame`, 1200×2000, `src=/Account/Sell/IacSellProgressList?menuCode=TDM506`
5. 공통 푸터: `.footer`
   - Top 이동, 도움말, 고객센터/정책 링크
6. 별도 약관 모달: `#TermsOfService`
   - 스타배송/셀러플렉스 약관, PDF 다운로드 및 외부 정책 링크

정적 상위 문서 기준 요소 수는 링크 178개, 버튼 36개, 입력 1개, iframe 1개이며 `form`, `table`, `select`는 0개다. 판매 데이터 테이블이 없다는 점이 iframe 미캡처를 뒷받침한다.

## JavaScript와 네트워크 관찰

- 인라인 스크립트는 URL 끝의 `#`를 제거하고, 전역 `token` 상수를 설정하며 Montelena 분석 스크립트를 비동기로 삽입한다.
- `scripts/005-external-822ae2c2e1b5.js` (`TplTerms.js`)는 jQuery 기반으로 약관 모달의 열기·닫기·탭 클릭/키보드(좌우/Enter/Space)를 처리하고, PDF 링크를 새 탭으로 연다.
- jQuery 1.7.1, jQuery UI 1.8.17, Montelena 및 navigator 래퍼 앱/React/디자인시스템/unit/vendor 번들이 선언돼 있다.
- 캡처본에 보이는 API 호출 코드(`fetch`, XHR, jQuery `$.ajax`)는 없다. 판매진행내역 API가 있다면 iframe 문서 또는 수집 실패한 외부 번들에 있을 가능성이 높다.
- 매니페스트상 외부 CSS 6개와 스크립트 8개가 로드 실패해 로컬 파일에는 오류 설명만 저장되어 있다. 따라서 레이아웃 상세와 외부 번들 행위의 정적 분석은 불완전하다.

## 보안 및 민감정보

**높음 — 인증 토큰 노출:** `page.html`과 분리된 인라인 JS에 서명된 JWT가 평문으로 포함되어 있다. 이 보고서에는 토큰 값을 재기록하지 않았다. 토큰 페이로드에는 로그인/판매자 식별자, 회원 번호, 발급·만료 시각, issuer/audience가 들어 있다. 스냅샷을 공유·커밋·백업 대상에서 즉시 제외하고, 실제 세션 토큰이라면 서버 측에서 폐기/재발급하는 것이 안전하다.

**중간 — 계정·운영정보 노출:** 메타 태그와 헤더에 판매자 ID/표시명, 마스터 권한 표기, 동시접속 인원(7명)이 포함된다. 외부 공유 시 계정 식별 및 운영 상태 노출로 이어진다.

**낮음/관찰:** 상위 문서에서 `rel="noreferrer"`를 사용한 외부 링크가 일부 있으나, `target="_blank"` 링크 전체에 `noopener`가 일관되게 적용되지는 않는다. 신뢰 경계가 다른 외부 사이트 링크라면 `noopener noreferrer` 통일을 검토할 만하다.
