# 문서 화면 프로토타입

`index.html`을 브라우저에서 열면 실행됩니다. 외부 패키지나 서버는 필요하지 않습니다.

스냅샷의 다크 테마 문서 화면과 19개 본문 블록을 HTML, CSS, JavaScript로 재구성했습니다. 사이드바와 목차, 문서 검색(`Ctrl+K`), 제목 및 블록 편집, 블록 추가·유형 변경·드래그 이동, 테마, 즐겨찾기, 텍스트 저장, 아이콘과 커버, 문서 도구 패널을 사용할 수 있습니다. 변경 내용은 브라우저 `localStorage`에 저장됩니다.

블록에서 `Enter`는 다음 블록을 만들고 `Shift+Enter`는 줄바꿈을 삽입합니다. 빈 블록에서 `/`를 누르면 블록 유형 메뉴가 열립니다. 더 보기 메뉴의 **원본 문서로 초기화**를 누르면 스냅샷의 초기 내용으로 돌아갑니다.
